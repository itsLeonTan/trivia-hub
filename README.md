# TriviaHub

TriviaHub is a simple trivia quiz web application built with JavaScript that uses the **Open Trivia Database (OpenTDB) API** to generate quiz questions. Players can answer 10 multiple-choice questions, receive a score at the end, and play again with a new set of questions.

This project was created primarily to practice working with **REST APIs**, fetching data asynchronously, and dynamically updating the DOM.
